# Best Card Forward

Live site: https://bybyyy.github.io/best-card-forward/

A credit card game: draft a wallet, spend a year at real businesses in real cities, and find out whether your cards earned their annual fees.

Final project for CSE 2004. The proposal and build plan are in [`docs/`](docs/).

## Running locally

```bash
npm install
npm run dev
```

## Deploying

Every push to `main` builds the site and publishes it to GitHub Pages (see `.github/workflows/deploy.yml`).
